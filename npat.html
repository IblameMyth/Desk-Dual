How to play

  1. Each round a random letter is picked. Everyone writes one word starting with it for Name, Place, Animal and Thing.
  2. You get 25 seconds. No peeking, no asking for help. With friends (2 to 10 players), each player takes their own 25 seconds on the same phone.
  3. 10 points for a valid answer nobody else wrote. 5 points if it matches another player’s word. 0 for a blank, an invalid word or a word starting with the wrong letter.
  4. Bonus rule (optional): 15 points if yours is the only valid answer in that column.
  5. Fictional names like Goku or Batman only count if you switched them on before the game.
  6. Words the game can’t check are marked unchecked. They count by default, but you can tap to reject one if it isn’t real.
  7. Play the chosen number of rounds. Highest total wins!
